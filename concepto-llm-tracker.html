Proceso Completo

Como funciona paso a paso

Desde que introduces tu negocio hasta que ves el dashboard con todos los insights.

1

Usuario introduce datos del negocio

Nombre, ciudad, sector, web y competidores opcionales. Con esto el sistema tiene contexto suficiente para generar preguntas inteligentes.

2

Generacion automatica de preguntas

El sistema genera 15-25 preguntas en 6 categorias diferentes, simulando lo que un cliente real preguntaria a la IA.

Conocimiento directo Recomendacion Comparativa Reputacion Servicios Precio
3

Consulta simultanea a OpenAI y Gemini

Cada pregunta se envia en paralelo a ambos LLMs. Se registra la respuesta completa, el tiempo de respuesta y los tokens usados.

OpenAI (GPT-4.1)
"Veterinaria San Marcos en Madrid es una clinica veterinaria ubicada en el barrio de Chamberi, conocida por su servicio de urgencias 24 horas y su equipo de cirujanos especializados..."
Gemini (2.5 Pro)
"San Marcos es una veterinaria en Madrid que ofrece servicios generales y de urgencia. Segun resenas en Google, los clientes destacan la atencion personalizada aunque algunos mencionan precios elevados..."
4

Analisis profundo de cada respuesta

Un LLM analista (separado) procesa cada respuesta y extrae metricas estructuradas:

Sentimiento — positivo, negativo, neutro + score 0-100
Posicion — en que lugar te menciona vs competidores
Precision — datos correctos vs incorrectos vs inventados
Mencion — si te nombra, te ignora o te confunde con otro
Temas — palabras clave y atributos asociados
Intencion — informar, recomendar, disuadir, comparar
5

Dashboard con todos los resultados

Visualizacion completa: comparativa entre LLMs, evolucion temporal, alertas de informacion incorrecta y recomendaciones de mejora.

Motor de Preguntas

25 preguntas en 6 categorias

Cada categoria simula un tipo diferente de busqueda que un cliente real haria en ChatGPT o Gemini.

Conocimiento Directo

Que sabe la IA sobre ti
"Que sabes sobre {empresa} en {ciudad}?"
"Donde esta ubicada {empresa}? Que servicios ofrece?"
"Cual es el horario y telefono de {empresa}?"
"Quien es el dueño o fundador de {empresa}?"
Mide: precision de datos, nivel de conocimiento, alucinaciones

Recomendacion

Te recomienda la IA?
"Cual es la mejor {sector} en {ciudad}?"
"Necesito un {servicio} para {caso}. Que me recomiendas en {zona}?"
"Dame un top 5 de {sector} en {ciudad}"
"Donde puedo llevar a mi {mascota} de urgencia en {ciudad}?"
Mide: posicion en ranking, frecuencia de mencion, contexto de recomendacion

Comparativa

Tu vs la competencia
"Que diferencia a {empresa} de {competidor}?"
"Es mejor {empresa} o {competidor} para {servicio}?"
"Compara precios entre {empresa} y {competidor}"
"Cual tiene mejores resenas, {empresa} o {competidor}?"
Mide: ventajas/desventajas percibidas, posicionamiento relativo

Reputacion

Que opinion tiene la IA
"Que opinan los clientes de {empresa}?"
"Tiene buena reputacion {empresa}?"
"Ha habido quejas o problemas con {empresa}?"
"Es confiable {empresa}? La recomendarias?"
Mide: sentimiento, tono, fuentes citadas, sesgo

Servicios Especificos

Conoce tus servicios?
"Ofrece {empresa} servicio de {servicio_especifico}?"
"Que especialidades tiene {empresa}?"
"Atienden emergencias en {empresa}?"
"Que tecnologia o equipamiento tiene {empresa}?"
Mide: cobertura de servicios conocidos, servicios inventados, lagunas

Precio y Accesibilidad

Como percibe tu precio
"Cuanto cuesta una consulta en {empresa}?"
"Es cara {empresa}? Hay opciones mas baratas?"
"Tiene {empresa} algun plan de financiacion o seguro?"
"Cual es la {sector} mas barata en {ciudad}?"
Mide: percepcion de precio, relacion calidad-precio, accesibilidad
Metricas del Dashboard

12 metricas clave que se extraen

Cada respuesta de cada LLM se analiza para extraer estas metricas. Se muestran por LLM y como promedio.

Sentiment Score

Puntuacion 0-100 del sentimiento general. Promedio de todas las respuestas. Positivo (>70), Neutro (40-70), Negativo (<40).

Visibility Score

% de preguntas en las que la IA te menciona. 100% = siempre presente. <30% = practicamente invisible.

Ranking Position

Posicion media cuando la IA lista multiples opciones. #1 = primera recomendacion, null = no aparece.

Accuracy Score

% de datos factuales correctos (direccion, telefono, servicios, horarios). Detecta alucinaciones.

Hallucination Rate

% de respuestas con informacion inventada (servicios que no existen, datos falsos). Critico detectarlo.

Brand Intent

Intencion predominante: Informar, Recomendar, Advertir, Comparar, Disuadir. Muestra el "tono" de la IA.

Topic Cloud

Nube de temas/atributos que la IA asocia a tu marca. Ej: "urgencias", "caro", "profesional", "moderno".

Competitor Mentions

Cuantas veces y que competidores mencionan junto a ti. Quienes son tu "vecindario" en la mente de la IA.

Response Confidence

Nivel de seguridad con que la IA habla de ti. "Segun tengo entendido..." vs "Sin duda, es la mejor..."

LLM Consistency

Que tan alineadas estan las respuestas de ChatGPT vs Gemini. Alta divergencia = la IA no tiene info clara.

Recommendation Rate

% de preguntas de recomendacion donde la IA te elige activamente. El KPI mas importante para conversion.

Knowledge Depth

Cuanta informacion detallada tiene la IA sobre ti. Superficial (solo nombre) vs Profundo (servicios, historia, equipo).

Modelo de Datos (Prisma)

model Business {
  id          Int       @id @default(autoincrement())
  name        String
  city        String
  sector      String
  website     String?
  competitors String[]
  analyses    Analysis[]
}

model Analysis {
  id          Int        @id @default(autoincrement())
  businessId  Int
  business    Business   @relation(...)
  status      AnalysisStatus
  totalScore  Float?
  createdAt   DateTime   @default(now())
  questions   Question[]
  metrics     Metric[]
}

model Question {
  id          Int        @id @default(autoincrement())
  analysisId  Int
  category    String     // recomendacion, reputacion...
  prompt      String
  responses   Response[]
}

model Response {
  id            Int      @id @default(autoincrement())
  questionId    Int
  llmProvider   String   // "openai" | "gemini"
  rawResponse   String
  sentiment     Float?
  position      Int?
  accuracy      Float?
  hallucination Boolean?
  intent        String?
  topics        String[]
  confidence    Float?
  tokensUsed    Int?
  responseTime  Int?     // ms
}
